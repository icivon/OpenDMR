# Codec 2 3200 解码与编码：标准流程笔记

M17 语音流每 40 ms 帧载两个 Codec 2 3200 帧（各 8 字节，20 ms）。Codec 2 没有独立的规范文档，权威定义是参考实现
（drowe67/codec2，LGPL-2.1）和它的算法说明 `doc/codec2.tex`。本笔记只记录算法、参数和常数（用自己的话），
`src/services/c2dec.c`（解码，第 1–8 节）和 `c2enc.c`（编码，第 9 节）按它自行实现，不含参考实现的代码。

## 1. 位流（64 位，MSB 先）

| 位 | 字段 | 说明 |
|---|---|---|
| 0 | v0 | 第一个 10 ms 子帧的清/浊音 |
| 1 | v1 | 第二个子帧的清/浊音 |
| 2–8 | Wo 索引（7 位） | 第二子帧的基频 |
| 9–13 | E 索引（5 位） | 第二子帧的 LPC 能量 |
| 14–63 | 10 × 5 位 | LSP 差分索引 |

**所有多位字段都是 Gray 码**（参考实现 `unpack()` 默认 gray=1）。

- 基频：Wo = Wo_min + (Wo_max − Wo_min)·i/128，Wo_min = 2π/160（50 Hz），Wo_max = 2π/20（400 Hz）。
  即 f0 = 50 + 350·i/128 Hz。谐波数 L = ⌊π/Wo⌋。
- 能量：E = 10^(dB/10)，dB = −10 + 50·i/32（−10 … 38.4 dB）。E 是**功率**量。
- LSP：差分标量量化，f₀ = d₀，fᵢ = fᵢ₋₁ + dᵢ（Hz），ωᵢ = π·fᵢ/4000。差分码本（32 项）：
  - 第 1–3、7–10 个：25, 50, …, 800 Hz（步长 25）
  - 第 4–6 个：25 … 200 Hz（步长 25，索引 0–7），然后 250 … 1400 Hz（步长 50，索引 8–31）
  - **解码时不做 LSP 最小间隔扩展**（3200 模式没有 bw_expand；这一步只在别的模式/编码端出现）。

## 2. 两个子帧的模型

第二子帧（model[1]）直接用解出的参数（**清音时也用解出的 Wo**，不换成 50 Hz）。第一子帧（model[0]）在上一帧的第二子帧（prev）和本帧第二子帧（next）之间插值：

- 清浊：取位 v0；但若 v0 = 浊、而 prev 与 next 都是清，则改为清。
- 基频：浊音时——prev、next 都浊取平均；只有 next 浊取 next；只有 prev 浊取 prev。清音时 Wo = Wo_min。
- 能量：几何平均 E0 = √(E_prev·E1)（即 dB 平均）。
- LSP：逐个算术平均（弧度）。

解码器初始状态：prev 为清音、Wo = Wo_min；prev LSP = i·π/11（i = 0…9，第一个是 0）；prev E = 1；激励相位 0；
背景噪声估计 0 dB。

## 3. 每个子帧：谐波幅度

1. LSP → LPC 系数 a₀…a₁₀（a₀ = 1），A(z) = Σ aₖ z⁻ᵏ = (P(z)+Q(z))/2，
   P = (1+z⁻¹)Π(1 − 2cosω_{偶} z⁻¹ + z⁻²)，Q = (1−z⁻¹)Π(1 − 2cosω_{奇} z⁻¹ + z⁻²)。
2. 在 512 点 DFT 网格上取 k = 0…255（ω_k = 2πk/512，每格 15.625 Hz）：Pw(k) = 1/(|A(ω_k)|² + 10⁻⁶)。
3. **LPC 后置滤波**（默认开启）：
   - W(k) = |A(ω_k/γ)|²，即系数 aₖγᵏ 的谱，γ = 0.5；
   - R(k) = √(W·Pw)；Pw(k) ← Pw(k)·R(k)^(2β)，β = 0.2；
   - 能量归一：Pw ← Pw·(ΣPw_前 + 10⁻⁴)/(ΣPw_后 + 10⁻⁴)·E（求和遍及 256 格）；
   - 低音补偿：k < 64（1 kHz 以下）Pw ×1.96（+3 dB）。
   （不开后置滤波时只是 Pw ← Pw·E。）
4. 谐波幅度按**带内能量求和**，不是在谐波频点取样：
   Aₘ = √(Σ_{k=aₘ}^{bₘ−1} Pw(k))，aₘ = ⌊(m−½)Wo/r + ½⌋，bₘ = ⌊(m+½)Wo/r + ½⌋（上限 256），r = 2π/512。
   对窄谱峰（相邻 LSP 很近）这和取样差别极大：峰落在哪个谐波带里，能量就归哪个谐波。
5. LPC 修正：f0 < 150 Hz 时 A₁ ×0.032。

## 4. 每个子帧：相位

- 激励相位：先 φ ← φ + Wo·80，再折回 [−π, π)。
- 合成滤波器相位：H_m = conj(A(b))，b = ⌊m·Wo/r + ½⌋（最近的网格点），即 arg H = −arg A(ω_b)。
- 浊音：θₘ = m·φ + arg Hₘ；清音：θₘ = 随机相位 + arg Hₘ。
  随机数：线性同余 next = next·1103515245 + 12345，值 = (next/65536) mod 32768，相位 = 2π·值/32767，next 初值 1。
- **背景噪声后处理**（`postfilter()`，另一个“后置滤波”）：
  e = 10·log10(ΣAₘ²/L) dB；若 e < 40 dB 且本子帧为清音，bg ← 0.9·bg + 0.1·e；
  浊音子帧里幅度 Aₘ < 10^((bg+6)/20) 的谐波，相位换成随机相位（不加 arg H）。

## 5. 每个子帧：合成（N = 80）

- 每个谐波放在 512 点 IDFT 的格点 bₘ = ⌊m·Wo·512/2π + ½⌋（上限 255）上，值 Aₘe^{jθₘ}，共轭对称，
  不归一化的实数 IFFT：s(n) = Σ 2Aₘ cos(2π bₘ n/512 + θₘ)。**合成频率被量化到 15.625 Hz 的格点上**，
  基音连续性靠每子帧更新的激励相位保持。
- 窗 Pn（长 160）：Pn(i) = i/80（i < 80），Pn(i) = 1 − (i−80)/80（i ≥ 80），即三角窗，相邻子帧和为 1。
- 重叠相加（缓冲 Sn 长 160）：
  1. Sn(i) ← Sn(i+80)，i = 0…78；Sn(79) ← 0；
  2. Sn(i) += s(i−79)·Pn(i)，i = 0…78；
  3. Sn(i) = s(i−79)·Pn(i)，i = 79…159；
  4. 输出 Sn(0…79)。
- 防震耳：子帧内最大**正**样值超过 30000 时，整子帧乘 1/over²（over = max/30000）。
- 限幅到 ±32767。

## 6. 定点实现要点（c2dec.c）

CPU 无 FPU（软件浮点乘约 1.6 µs），每谐波、每格、每样点都不用浮点：

- |A(ω)| 和 arg A 用乘积形式直接由 LSP 求（A = e^{−j5.5ω}(cos(ω/2)Π(2cosω − 2cosω_偶) + j sin(ω/2)Π(2cosω − 2cosω_奇))），
  尾数/指数归一化防溢出，CORDIC 求角度——比 FFT 后的 LPC 系数在尖峰附近精确得多。
- W(k)（γ = 0.5，系数 aₖ/2ᵏ，平滑无尖峰）用 LPC 系数直接求和。
- 功率谱、后置滤波、带内求和、开方都在 log2 域（Q16）做，求和时按块指数转回线性。
- 振荡器组：相位累加器 + 正弦表，频率正好是格点频率。

`m17/py/c2_3200_model.py` 是按本笔记写的浮点模型。和参考解码器（热点上的 libcodec2 1.0.5）比：

  无法也无须逐位复现。

## 9. 编码（3200）

M17 发射用。权威定义同样是参考实现（`codec2_encode_3200()`、`analyse_one_frame()`、`nlp.c`、`sine.c`、`lpc.c`、
`lsp.c`、`quantise.c`），这里只记算法和常数。`src/services/c2enc.c` 按本节实现，`m17/py/c2_3200_enc_model.py` 是
浮点模型。

### 9.1 一帧（20 ms，160 个样点）

1. 第一个 10 ms 子帧做分析（9.2–9.5），只取清/浊 v0；
2. 第二个子帧做分析，取 v1 和基频 Wo；
3. 用此时的分析缓冲（9.2 的 Sn）做 LPC，得能量 E 和 10 个 LSP（9.6）；
4. 量化、打包（9.7）。

两个子帧的基频只发第二个的，第一个子帧在解码端插值（第 2 节）。

### 9.2 分析缓冲与谱

- Sn：最近 320 个样点（40 ms），每子帧左移 80、末尾补新的 80 个；初值全为 **1.0**（不是 0）。
- 分析窗 w：长 320，只有中间 278 个非零：w[21 + j] = 0.5 − 0.5 cos(2πj/278)，j = 0…277（Hann 形，尽管参考实现
  的注释叫 Hamming）；再整体乘 1/√(512 Σw²)，使频域幅度直接可用。
- 谱 Sw：512 点 FFT，输入以第 160 个样点为时间原点：x[n] = Sn[160+n]·w[160+n]（n = 0…138），
  x[512−139+i] = Sn[21+i]·w[21+i]（i = 0…138），其余为 0。
- 窗谱 W：同样摆放的 w 的 512 点 FFT 实部，循环移位使 W[256] 对应 0 频。只在 9.5 用。

### 9.3 基音估计（NLP，非线性基音）

在 8 kHz 的平方信号上找基频峰。每子帧：

1. 新 80 个样点平方：sq = s²；
2. 直流陷波：y = sq − sq₋₁ + 0.95·y₋₁，进入下一步的是 **y + 1.0**（参考实现为避开 FFT 的慢速路径加的常数；
   对全零输入它决定结果）；
3. 48 阶 600 Hz 低通 FIR（固定系数表，对称）；
4. 缓冲 320 个低通输出，每 5 个取一个（64 个，位置 0, 5, …, 315），乘 64 点 Hann 窗
   0.5 − 0.5 cos(2πi/63)，补零到 512 点做 FFT，取 |F|²；
5. 全局峰：bin 16…128（f0 = bin·8000/2560 Hz，即 50…400 Hz）中最大者 gmax_bin；
6. 子倍数检查（偏向低基频）：mult = 2, 3, … 直到 gmax_bin/mult < 16：b = gmax_bin/mult，在 [⌊0.8b⌋, ⌊1.2b⌋]
   （下限 16）内找最大值；若它大于门限且是局部峰（大于左右邻），就把候选改成它。门限 0.3·gmax，若上一子帧的
   基频 bin 落在该区间内（严格在内）则 0.15·gmax（基音跟踪）；
7. 结果 f0 = bin·3.125 Hz，基音周期 P = 8000/f0（样点），记为下一子帧的“上一基频”（初值 50 Hz）。

### 9.4 基音细化

在 Sw 上做谐波能量和：对候选周期 p，Wo = 2π/p，E(p) = Σ_{m=1..L} |Sw(round(m·Wo/r))|²（r = 2π/512，
L = ⌊π/Wo_初⌋ 由细化前的基频定，bin 超过 256 时用共轭镜像）。

- 粗：p = P−5 … P+5，步长 1；
- 细：p = p粗−1 … p粗+1，步长 0.25；
- 取 E 最大者（相等取先者），再限制在 Wo ∈ [2π/160, 2π/20]；
- L = ⌊π/Wo⌋，若 Wo·L ≥ 0.95π 则 L 减 1。

### 9.5 清/浊判决（MBE）

- 谐波幅度：A_m² = Σ_{k=a_m}^{b_m−1} |Sw(k)|²，a_m = ⌊(m−½)·Wo/r + ½⌋，b_m = ⌊(m+½)·Wo/r + ½⌋。
- 只看 1 kHz 以下的谐波 l = 1 … ⌊L/4⌋：在 [⌈(l−½)Wo/r⌉, ⌈(l+½)Wo/r⌉) 上用以谐波为中心的窗谱 W 拟合
  （W 的偏移 ⌊256.5 − l·Wo/r⌋）：A = ΣSw·W / ΣW²，误差 ε += Σ|Sw − A·W|²；
- SNR = 10 log10(Σ_{l≤L/4} A_l² / ε)，**> 6 dB 为浊音**；
- 修正：e_low = Σ_{l≤L/2} A_l²，e_high = Σ_{L/2≤l≤L} A_l²（第 L/2 个两边都算），比值 r_dB：
  清音而 r_dB > 10 改浊；浊音而 r_dB < −10 改清；浊音、r_dB < −4 且 f0 ≤ 60 Hz 也改清
  （噪声常被估成 50 Hz 基频）。

### 9.6 LPC、能量、LSP

在第二子帧之后的 Sn 上（同一个分析窗 w，320 点）：

1. Wn = Sn·w；全零时 LSP 取 πi/10、能量 0；
2. 自相关 R₀…R₁₀，Levinson-Durbin 得 a₀ = 1, a₁…a₁₀（反射系数 |k| > 1 时置 0）；
3. **能量 E = Σ aₖ Rₖ**（预测误差功率，在带宽扩展之前算）；
4. 15 Hz 带宽扩展：aₖ ← aₖ·0.994ᵏ；
5. LSP：P′、Q′（各 6 个系数：P′₀ = Q′₀ = 1，P′ᵢ = aᵢ + a₁₁₋ᵢ − P′ᵢ₋₁，Q′ᵢ = aᵢ − a₁₁₋ᵢ + Q′ᵢ₋₁，
   i = 1…5，再把 P′₀…P′₄、Q′₀…Q′₄ 乘 2），在 x = cos ω 上用切比雪夫多项式 Σ c₅₋ᵢ Tᵢ(x) 求根：
   从 x = 1 起以 0.01 为步长往下走，P′ 和 Q′ 交替（第 0、2… 个根在 P′ 上），遇到变号（或右端恰为 0）后二分
   6 次，取最后的中点为根，下一个根从它开始找；x 低于 −1 仍未凑满 10 个根时 LSP 取 πi/10。ω = arccos x。

### 9.7 量化与打包

- Wo：i = ⌊128·(Wo − Wo_min)/(Wo_max − Wo_min) + ½⌋，限 0…127；
- E：i = ⌊32·(10 log10 E + 10)/50 + ½⌋，限 0…31（E = 0 时 0）；
- LSP（Hz，f = 4000ω/π）：差分标量量化，d₀ = f₀，dᵢ = fᵢ − f̂ᵢ₋₁（与已量化的前一个之差），在第 1 节的差分码本中
  取最近值（相等取先者），f̂ᵢ = f̂ᵢ₋₁ + 码本值；
- 字段顺序同第 1 节，每个字段 Gray 码。

### 9.8 定点实现要点（c2enc.c）

- 512 点实数 FFT 由 256 点复数 FFT 加拆分得到，块浮点（每级输入超限就整体右移一位）。NLP 的谱需要高精度：平方
  信号的低频分量比 bin 16 附近高约 55 dB，Q15 的 FFT 舍入噪声会淹没它，所以数据保持 28 位、乘 Q15 旋转因子时拆
  成两个 15 位乘积（CPU 只有 32 位乘法）；64 个输入在位反序下每 8 个一组相同，前三级省去。语音谱用普通 Q15。
- NLP 的陷波在 Q8（64 位）里做，0.95 用精确的除以 20（两次 32 位除法）；截断误差会累积成直流偏差，平坦谱峰
  就会移一格。
- 细化、清浊判决用 64 位和；SNR、能量比的比较化成整数乘法（10^0.6 ≈ 3981/1000 等）。
- LPC：自相关在 14 位窗后信号上整数算；Levinson、带宽扩展、P′/Q′ 用 float（每帧几十次运算）；求根时网格上
  先用 Q15 算多项式，值离 0 太近（符号不可信）时改用 Q29，二分全用 Q29；位置 Q30（网格步长 0.01 精确）；
  arccos 由 √((1−x)(1+x)) 和 CORDIC 求。
- 收音机上（CK803S）编一帧 20 ms 约 8.2 ms：NLP 滤波 0.7，NLP 谱 1.8，语音谱 2.9，细化 0.4，清浊 0.6，LPC 1.8。
